# ve-assistant

An AI-powered Python application that identifies highlights in long-form videos, extracts precise clip segments, and exports clean files ready for editing.

Ideal for streamers, podcasters, and content creators who want to generate engaging highlights quickly with minimal manual effort.

## Features

- Detects notable moments in long-form videos using AI
- Extracts precise video segments
- Exports clips in an editor-ready format
- Includes audio-only downloads in MP3 format
- Supports a simple workflow for downloading source videos

## `vidl`

The `vidl` utility downloads videos using `yt-dlp`.

### Requirements

- Windows
- `yt-dlp`
- A downloadable video URL

### Usage

1. Download `yt-dlp`.
2. Place the `yt-dlp` executable inside the `/vidl` directory.
3. Run the `.bat` file.
4. Paste the URL of the video you want to download.
5. Follow the prompts to select the desired download format.

### Available Download Option

- MP3/audio-only downloads
